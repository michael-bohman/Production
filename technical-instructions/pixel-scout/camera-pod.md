# Camera Pod

## Required Materials



## Notes:

These instructions end with two separate components, the back with the rangefinders and the front with the cameras. These halves will be joined in a later instruction set.

## Guide

{% stepper %}
{% step %}
### Insert the Rangefinder

Place the rangefinders inside the housing and secure using 4 screws (M3x6mm Flathead) each and Loctite.
{% endstep %}

{% step %}
### Orient the Cameras

Assign 2 cameras for each pod, they should be in succession. The LOWER serial number camera will be designated as the PRIMARY.
{% endstep %}

{% step %}
### Attach the Cameras

1. hold the cameras in place and insert the screws (91249A615) about halfway with Loctite.
   1. It may be easiest to screw in the back ones first.
2. Go back and tighten all screws the rest of the way.

<figure><img src="../../.gitbook/assets/IMG_7655.jpg" alt="" width="375"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Attach the wires

1. For each camera, take off the back cover.
2. Attach the PSDK cable to the micro-USB breakout board.

<figure><img src="../../.gitbook/assets/IMG_7657 (1).jpg" alt="" width="375"><figcaption></figcaption></figure>

4. Route the cable to the correct corner.
   1. Primary will go to the close corner
   2. Secondary will go to the far corner

| Primary                                                                        | Secondary                                                                      |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| <img src="../../.gitbook/assets/IMG_7656 (2).jpg" alt="" data-size="original"> | <img src="../../.gitbook/assets/IMG_7658 (1).jpg" alt="" data-size="original"> |

5. Place the cover back on, ensuring the cable stays in place and is not pinched.
6. Re-apply Loctite to the screws and secure the cover.
{% endstep %}
{% endstepper %}
