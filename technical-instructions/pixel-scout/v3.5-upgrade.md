## Guide

1. Take the back off the antenna to gain access to the P900 board
2. Reprogram it to be the same as a V4
   1. Needs to be changed to master.
   2. Radio Net ID will be 32011-100xx. (xx is serial number)
3. Configure a new base station
4. Build a ground module
   1. P900 board will pair with that of step 2
5. If focus is not touched, only a short verification flight is required.
6. Put everything in a new v4 case.
   1. Will use all the cables from the v3 cases except the 3 inch USB-C.
