**Changing Static IP:**

1. Win + R
2. ncpa.cpl
3. Ethernet > Right Click > Properties
4. Double Click Internet Protocol Version 4 (TCP/IPv4)
5. Select Use the following IP address:
   1. Type 192.168.5.242
   2. tab to auto-populate Subnet mask
   3. click ok

## Guide

### Antenna

1. Take the back off the antenna to gain access to the P900 board
2. Reprogram it to be the same as a V4
   1. [3-c-p900-radio-programming.md](assembly-steps/3-c-p900-radio-programming.md "mention")
   2. Needs to be changed to master.
   3. Radio Net ID will be 32011-100xx. (xx is serial number)
3. Disassemble the ends of the antenna to remove and update the f9p boards
   1. (HPG-1.51)



### Base Station

1. Configure a new base station
   1. [initial-setup.md](emlid-base-station/initial-setup.md "mention")
   2. The Wi-Fi name will be "WeedScout-XXX" instead of "PixelScout-XXX" and the password will be "weedscout" instead of "pixelscout"
2. Build a ground module
   1. [ground-module-assembly.md](../../production-documentation-1/rtk-ppk/ground-module-assembly.md "mention")
   2. P900 board will pair with that of step 2
      1. [3-c-p900-radio-programming.md](assembly-steps/3-c-p900-radio-programming.md "mention")
3. Assemble the tripod
   1. [#test-flight-packing](calibration-and-verification/case-assembling-and-packing.md#test-flight-packing "mention") (step 5: Assemble and place the tripod into the large, long slot in the case foam.)

### Gimbal

{% hint style="info" %}
If focus was changed. Make sure camera is back to WeedScout configurations before continuing. Power and connect to the cameras separately to update.
{% endhint %}

1. Update the camera firmware
   1. Backup any sessions (like focus or BPR) before updating firmware
2. Check firmware
   1. 192.168.5.130 is 2024080100
   2. 192.168.5.131/ver.json
      1. swCfg: 'DEFAULT' --> ver: 2024051500
      2. swCfg: 'DEFAULT3' --> ver: 2025021400
   3. 192.168.5.132 (SBG) is 6.0.5585 (stable)
      1. If not, upload the file from the upgrade files folder.
3. Check the factory config for each camera
   1. Open Command Prompt
   2. Connect to the powered-on gimbal using ethernet.
      1. Make sure to change your static IP.
   3. Type the following code one line at a time hitting 'enter' after each line.
   4. Look for 'name:weedscout3-1-spot' for the primary camera or 'name:weedscout3-2' for the secondary camera.

```
del .ssh\known_hosts
ssh root@192.168.5.141     %% or 192.168.5.142 for secondary cameras
yes
6636cedar              %% note: this will not appear, it is still recording what you type.
cd /media/persist/camera-app/factory-config/
cat meta.yaml
exit
```

4. If not found ('factory-config' does not auto populate with tab or error occurs if typed in completely)
   1. Set the factory default configs
      1. copy the config folder from the info folder to the firmware folder, rename to 'factory-config'
         1. Power Cycle the system to apply this change.
         2. Check the factory configs again.
5. Apply Bad Pixel Replacement
   1. [65r-bad-pixel-replacemnt.md](../65r/65r-bad-pixel-replacemnt.md "mention")
6. Connect USB-power to the ground radio while antenna is being powered and ensure the green lights on the ground radio illuminate solid.
7. If focus is not touched, only a short verification flight is required.
   1. If focus is adjusted or the cameras were repositioned, Calibration is required, refer to [calibration-and-verification](calibration-and-verification/ "mention")
8. Put everything in a new v4 case.
   1. Will use only the cables from the v3 cases except...
      1. A new 3 inch USB-C cable
      2. Do not use the micro-USB or power bank from WeedScout case
   2. Make sure to use the green stickers that say "WeedScout" on the outside of the case (PN 35430)





## V3 Upgrade Test Flight (if calibration isn't required)

Flight Route Settings

{% hint style="info" %}
Some of these settings can be changed. This is just what was used for the first V3 upgrade test flight.
{% endhint %}

* Area: \~100'x100'
* Drone: M350/M300 RTK
* Camera: Custom > 65R - 60mm
* Ortho GSD (changes automatically when you change other settings): 0.16
* Altitude: 100 ft ALT
* Elevation Optimization: OFF
* Safe Takeoff Altitude: 80' (adjustable)
* Speed: 5mph
* Course Angle: 90 (adjustable)
* Upon Completion: Return to Home
* Target Surface to Takeoff Point: 0 (adjustable if environment allows)
* Side Overlap Ratio: 50
* Frontal Overlap Ratio: 50
* Margin: 0
* Photo Mode: Timed Interval Shot
* Custom Camera Angle: OFF
* Route Start Point: adjustable
* Takeoff Speed: 33.5 mph (adjustable)

Should result in \~1-1.5 minutes and \~30 pictures
