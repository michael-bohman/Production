# 🚧 V3.5 Upgrade

When upgrading a weedscout v3 to a 3.5, follow this quick guide on the steps required.

## Notes

Leftover material (cases, etc) will be returned to the customer.

**Changing Static IP:**

1. Win + R
2. ncpa.cpl
3. Ethernet > Right Click > Properties
4. Double Click Internet Protocol Version 4 (TCP/IPv4)
5. Select Use the following IP address:
   1. Type 192.168.5.242
   2. tab to auto-populate Subnet mask
   3. click ok



**Checking Factory Config**

1. Open Command Prompt
2. Connect to the powered-on gimbal using ethernet.
   1. Make sure to change your static IP.
3. Type the following one line at a time hitting 'enter' after each one.

```
del .ssh\known_hosts
ssh root@192.168.5.141
yes
6636cedar
cd /media/persist/camera-app/factory-config/
cat meta.yaml
```

3. Look for 'name:weedscout3-1-spot' for the primary camera.
4. Type:

```
exit
```

5. Repeat steps 3-5 using '192.168.5.142' and look for 'name:weedscout3-2' for the secondary camera

## Guide

1. Take the back off the antenna to gain access to the P900 board
2. Reprogram it to be the same as a V4
   1. [3-c-p900-radio-programming.md](assembly-steps/3-c-p900-radio-programming.md "mention")
   2. Needs to be changed to master.
   3. Radio Net ID will be 32011-100xx. (xx is serial number)
3. Configure a new base station
   1. [initial-setup.md](emlid-base-station/initial-setup.md "mention")
4. Build a ground module
   1. [ground-module-assembly.md](../../production-documentation-1/rtk-ppk/ground-module-assembly.md "mention")
   2. P900 board will pair with that of step 2
      1. [3-c-p900-radio-programming.md](assembly-steps/3-c-p900-radio-programming.md "mention")
5. Assemble the tripod
   1. [#test-flight-packing](calibration-and-verification/case-packing-needs-pictures.md#test-flight-packing "mention") (step 5: Assemble and place the tripod into the large, long slot in the case foam.)
6. If focus is not touched, only a short verification flight is required.
7. Put everything in a new v4 case.
   1. Will use all the cables from the v3 cases except the 3 inch USB-C.
8. Update things.
   1. camera firmware
   2. double check factory config
   3. f9p firmware (HPG-1.51)
      1. Take off antenna and bottom plate, connect to board directly
   4. Firmware (needs to be powered by drone)
      1. 192.168.5.130 is 2024080100
      2. 192.168.5.131/ver.json
         1. swCfg: 'DEFAULT' --> ver: 2024051500
         2. swCfg: 'DEFAULT3' --> ver: 2025021400
      3. 192.168.5.132 (SBG) is 6.0.5585 (stable)





## V3 Upgrade Test Flight

Flight Route Settings

Some of these settings can be changed. This is just what was used for the first V3 upgrade test flight.

* Drone: M350/M300 RTK
* Camera: Custom > 65R - 60mm
* Ortho GSD (changes automatically when you change other settings): 0.16
* Altitude: 100 ft ALT
* Elevation Optimization: OFF
* Safe Takeoff Altitiude: 80' (adjustable)
* Speed: 5mph
* Course Angle: 90 (adjustable)
* Upon Completion: Return to Home
* Target Surface to Takeoff Point: 0 (adjustable if environment allows)
* Side Overlap Ratio: 50
* Frontal Overlap Ratio: 50
* Margin: 0
* Photo Mode: Timed Interval Shot
* Custom Camera Angle: OFF
* Route Start Point: adjustable
* Takeoff Speed: 33.5 mph (adjustable)

Should result in \~1-1.5 minutes and \~30 pictures
