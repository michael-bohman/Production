# Camera Checkin IN PROGRESS

## Guide

1. Plug in the camera via USB-C and turn on the power.
2. Navigate to taurus>Production>Sensors>6X — Check QC>6X-65R\_Checkin
   1. Note: both 65R and 6X use the same program
3. In another file explorer window, navigate to 192.168.42.1>data>snapshots
4. Rename the session folder that represents the flight test to 'Flight Test'.
5. Open the session folder and check multiple photos from each sensor for any abnormalities.
6. Open a browser and navigate to 192.168.42.1, this will be used to find the firmware version and sensor configuration.
7. Navigate back to the check in folder and run the application '6X-65R\_Checkin\_2.0.7.exe'
8. Follow the steps in the program. Refer to the following expandable snippets for an explanation on each step if needed.

<summary>Visual Check</summary>

Check the following areas for any abnormalities

* Screws are all in place, tight, undamaged, and clean
* No scratches/blemishes on any part of the exterior of the camera or gimbal
* No gaps between components
* Stickers are in place, straight, undamaged, and with clean edges
* Snakeskin and wires are not pinched/out of place in gimbal or between gimbal and camera

{% hint style="info" %}
This is not an all-encompassing list. Use your best judgement for anything not listed.
{% endhint %}
