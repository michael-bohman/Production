# Board Programming

## Notes

* These steps are different than usual. They can happen at different times.
* Batch Files are found here:
  * "\as-taurus.jdnet.deere.com\Production\Technical Packages\6X ARRAY\6X Array Tech Package"
* Use the same PICkit™3 as used with the PixelScout systems.



## Guide

### Front board (Dual Comms)

The front board may be programmed before assembling it into the camera pod. This is easiest because there's more room to plug things in.

1. Power the board using a 24V barrel connector in the front.
2. Plug the PICkit™3 into the 'PROG' port on the board and into the USB port on your computer.
3. Run the 'Front Board Program' file.
4. Wait for a red heartbeat LED and the program to complete before unplugging everything.
