# Gitbook Page Export Guide

NOTE: Pandoc and MikTex are required for this operation. Pandoc converts file between types and MikTex is a LaTex interpreter which is needed for PDF creation. Both can be found in the Software Installation Guide



## Notes

For a quick export without care for neatness, click on the 3 dots at the top and click 'Export to PDF'. Select the pages and export it. The rest of this guide is for making well-organized and neat documents.
