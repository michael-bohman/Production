# Task Breakdown

## Tags

| Tag                               | Usage                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------- |
| Blue (Use Yellow until available) | Records progress through normal procedures/changing hands                          |
| Yellow                            | Used when a Product has to be put aside/transferred out of a normal transfer stage |
| Green                             | Product is ready for Ship/Final QC                                                 |
| Red                               | Indicates an issue with the product                                                |
