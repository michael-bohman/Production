# Reflectance Panel Shipping QC

## Documents Needed

1. Sales Order&#x20;
2. Shipping Label
3. Packing List
4. Build

## QC

* Go to the QC rack with your computer&#x20;

### Reflectance Panel Number

1. Locate number of reflectance panel being shipped&#x20;
2. Go to this file location in Taurus
   1. \\\taurus\Production\Systems & Kits\21226-00 — Reflectance Panel.
3. Locate your Sales Order folder
4. Confirm the number on reflectance panel is the same in the SO folder
   1. Photo naming convention: "Panel XXXX" where XXXX is the number on the sticker.
5. Correct any issues that appear

### Address Confirmation

1. Confirm the shipping label is the same as the address on the sales order
2. Confirm Tracking number is the same on the Packing List&#x20;
3. Correct any issues that appear&#x20;

### Ship Package

1. Insert bubble wrap for safe shipping&#x20;
2. Place reflectance panel in box, face up&#x20;
3. Place Packing List on top of reflectance panel
4. Place sticker on top&#x20;
5. Close up box
6. Tape around edges&#x20;
7. Tape/stick-on label to the box&#x20;
8. Place in the shipment zone
