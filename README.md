# Production Documentation

The Production Documentation space is broken down into different groups. Below is an explanation for each group.

<details>

<summary>Technical Instructions</summary>

The **Technical Instructions** group includes everything needed for building/programming/focusing every product currently in production. It is organized by product(sensor, system, or kit).

</details>

<details>

<summary>Fault Isolation</summary>

The **Fault Isolation** group is a record of problems we've encountered and how we fixed them.

</details>

<details>

<summary>QC Shipping</summary>

The **QC Shipping** group has guides on how to QC products, how to pack them, and how to ship them. It also includes a guide on how to use shipping company software.

</details>

<details>

<summary>Space and General</summary>

the **Space and General** group has misc. pages with logistical guides and reference material.

</details>

### Highlighted Text on Pages

* <mark style="color:yellow;">Item numbers are highlighted in yellow and correspond to the drawing. The numbers in the parenthesis are the McMaster screw number that correspond to the screw bins.</mark>&#x20;
  * example: <mark style="color:yellow;">Item #10 (92217A101)</mark>
* <mark style="color:blue;">Any computer buttons needed to be clicked will be highlighted in blue</mark>
